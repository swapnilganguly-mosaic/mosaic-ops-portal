# ⚠️ Deprecated — no longer needed

This portal was a Google Sign-In gated wrapper around two separate tools (MRP Tool and
Production Scheduler). Both have since been merged into a single app: **`mrp-forward`**
(Production Scheduler is now its "6 · Scheduler" tab).

Per team decision, this repo is no longer used — no sign-in gate, direct access to the
merged tool instead.

**Use this instead:** https://mrp-forward.vercel.app

**Repo:** https://github.com/swapnilganguly-mosaic/mrp-forward

This repo and its Vercel deployment (`mosaic-ops-portal.vercel.app`) are kept around for
reference only. Do not build on top of this repo going forward.
